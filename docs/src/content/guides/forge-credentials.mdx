Agents push branches and the server reads pull requests, so an engine needs credentials for each forge. A personal token on a shared engine makes every agent act as one person, and it stays valid on disk until it expires. Our engine uses credentials that belong to the engine and expire within a day.

## GitHub

The engine acts as a GitHub App. The App's private key signs a request that GitHub exchanges for a token. That token lasts an hour and reaches only the repositories the App is installed on.

Register the App with no webhook. Give it read and write access to contents, pull requests, issues and workflows, and install it only on the repositories the engine should work in. Store its private key in Secrets Manager as `komrad/github-app`, as JSON with the key under `private_key`. At boot, the machine copies the key into memory, so the key never reaches the data volume or an image.

The <Setting path="github_app" label="[github_app]" /> table in komrad's config names the App's id, its installation id and the key's path. <Command path="github token" /> prints a token when the table is correct.

Git gets its token from <Command path="github credential" />, which the image sets as git's credential helper for github.com. The helper mints a token for each push, so no token is stored.

The server uses the App for its own forge connection too. Connect it with <Command path="forge connect" args="github.com --method github-app --engine remote" />.

## GitLab

GitLab has no equivalent of GitHub Apps, so the engine uses a token that the server rotates. Connect it with <Command path="forge connect" args="gitlab.com --method rotating-token" /> and pipe in a personal access token with the api scope. The server rotates the token immediately, so the token you piped in stops working. It then rotates the token every day.

Git gets the current token from <Command path="gitlab credential" />. The image sets that helper for gitlab.com. A self-hosted GitLab needs its own line, run as root:

```sh
git config --system credential.https://git.example.com.helper '!komrad gitlab credential'
```

## Rotating the App key

Generate a new key in the App's settings and store it in the secret. The machine reads the key only at boot, so reboot it or rerun the key unit, as [runbooks](../runbooks/#rotating-the-github-app-key) shows. Then delete the old key from the App.
