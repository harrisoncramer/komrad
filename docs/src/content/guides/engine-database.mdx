Postgres holds everything an engine knows: every workflow, task, agent, message and review, and who's allowed in. Komrad doesn't connect to it as one all-powerful user. It uses three logins, and each can do only what its job calls for.

## Three logins

<figure>
  <img
    src={link("/diagrams/engine-database.png")}
    alt="Migrate, ensure and grant connect as the owner login, which owns the schema. The server connects as the engine login, and the MCP query tools as the reader login. Both reach only one engine's rows."
  />
</figure>

The owner login owns the schema. It's what you use to migrate the database and to set up engines, and the server itself never touches it.

The engine login is what the server runs as day to day. <Command path="engine ensure" /> creates it, and from then on everything the server writes belongs to that engine. Postgres hides every other engine's rows from it, so several engines can share one database without seeing each other's work.

The reader login can see the same rows as the engine login, but it can't change anything. Agents' database queries run through it, so an agent poking around the database can't break it by accident.

## On our engine

Our database runs on RDS, which creates the owner login and keeps its password in AWS Secrets Manager. We never copy that password onto the machine. Whenever the machine needs the owner, it reads the secret fresh.

That happens at boot, on every deploy, and once an hour. Each time, the machine migrates the database, makes sure the engine's login exists, and hands the server its connection string. Running it on every deploy means a new migration always lands before the new server starts. Running it hourly means that when RDS rotates the owner's password, the machine picks up the new one without anyone stepping in.

## Backups

RDS keeps a week of automatic backups. Terraform also has deletion protection switched on for the database, so tearing the engine down won't take the data with it unless you turn that off first. [Runbooks](../runbooks/#tearing-it-down) covers it.
