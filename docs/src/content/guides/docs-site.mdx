The docs site is separate from the engine, and an engine doesn't need it. Astro builds the site as static files, a private S3 bucket holds them, and CloudFront serves them at komrad.dev.

## Hosting

Each build lives under its own prefix in the bucket. `latest/` follows main, and each release adds a prefix named after its tag, such as `v0.4.0/`. A `versions.json` file at the bucket root lists the versions for the site's version picker.

A CloudFront function handles each request before CloudFront reads the bucket. It redirects any hostname other than komrad.dev to komrad.dev, sends `/` to `/latest/`, and adds `index.html` to directory paths, because a private bucket doesn't serve index pages.

Cloudflare hosts DNS for every domain. The certificate comes from AWS Certificate Manager, and Terraform validates it with records in Cloudflare. komrad.ai, komrade.app and komrade.dev redirect to komrad.dev through Cloudflare's redirect rules and never reach AWS.

## Publishing

`docs-deploy.yml` publishes `latest` on any push to main that changes the docs, their tasks or their infrastructure. The release workflow calls it to publish each version. The workflow assumes a role that can write to the bucket and clear CloudFront's cache, and can't reach the engine.

To publish by hand, run `mise run docs:deploy latest`, or pass a version instead of `latest`.

The panel recordings in the guides live under `media/` in the bucket, outside any version, so every version shows the newest recording. `mise run docs:recordings` records them against a throwaway instance, and `mise run infra:docs:recordings upload` publishes them.

## Infrastructure

The Terraform lives in [`infra/docs`](https://github.com/harrisoncramer/komrad/tree/main/infra/docs). It keeps its state in the engine's state bucket and reuses the GitHub trust the engine stack creates, so apply the engine stack first. Then run `mise run infra:docs:init` and `mise run infra:docs:apply`, with `CLOUDFLARE_API_TOKEN` set to a token that can edit DNS and redirect rules on each domain.
