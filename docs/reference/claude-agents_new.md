## claude-agents new

Create a background agent session non-interactively

```
claude-agents new [flags]
```

### Options

```
      --client string   invoking tmux client
      --dir string      working directory (blank = current)
      --flags string    extra claude flags
  -h, --help            help for new
      --prompt string   initial prompt
      --title string    session title (blank auto-names)
```
