# komrade

Komrade is a terminal-based agent manager. It runs Claude and Codex agents via tmux, keeps track of them, and lets them work together.

Use komrade to manage, restore, and search through old agent sessions, launch and manage them with komrade's MCP, schedule agents, and much more.

It's designed to be familiar to terminal power users.

Read more in komrade's [https://komrade.dev/latest/guides/](docs).
