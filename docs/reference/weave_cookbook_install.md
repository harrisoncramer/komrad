## weave cookbook install

Install a cookbook's actions, workflow, and schedule

```
weave cookbook install <name> [flags]
```

### Options

```
      --cwd string   override the cookbook's default working directory
  -h, --help         help for install
```

### Options inherited from parent commands

```
      --config stringArray   path to a config TOML, repeatable, later files win over earlier ones
```
