Komrad's engine uses forge credentials that belong to the engine and stop working within a day. A personal token would make every agent act as the person who made it, and it would stay valid on the engine's disk for as long as the token lasts.

## GitHub

The engine acts as a GitHub App. It signs a request with the App's private key, and GitHub answers with a token that lasts an hour and reaches only the repositories the App is installed on.

Register the App without a webhook. It needs read and write access to contents, pull requests, issues and workflows. Install it only on the repositories the engine should work in. Store its private key in Secrets Manager as `komrad/github-app`, as JSON with the key under `private_key`. The machine copies the key into memory at boot, so the key never touches the data volume or an image.

The <Setting path="github_app" label="[github_app]" /> table in komrad's config names the App's id, its installation id and the path to the key. If the table is right, <Command path="github token" /> prints a token.

Git gets its token from <Command path="github credential" />, which the image sets as git's credential helper for github.com. The helper mints a fresh token for each push, so the engine never stores one.

The server uses the App for its own connection to GitHub as well. Connect it with <Command path="forge connect" args="github.com --method github-app --engine remote" />.

## GitLab

GitLab has nothing like GitHub Apps, so the engine uses a token that the server rotates. Connect it with <Command path="forge connect" args="gitlab.com --method rotating-token" /> and pipe in a personal access token with the api scope. The server rotates that token right away, so the one you piped in stops working, and from then on it rotates the token every day.

Git reads the current token from <Command path="gitlab credential" />, which the image sets as the helper for gitlab.com. A self-hosted GitLab needs its own helper line, run as root:

```sh
git config --system credential.https://git.example.com.helper '!komrad gitlab credential'
```

## Rotating the App key

Generate a new key in the App's settings and store it in the secret. The machine reads the key only at boot, so either reboot it or rerun the key unit, as [runbooks](../runbooks/#rotating-the-github-app-key) shows. Once the new key works, delete the old one from the App.
