## How it's served

The site is static. Astro builds it, a private S3 bucket holds the files, and CloudFront serves them at komrad.dev. Cloudflare handles DNS for all of our domains, and the other ones, like komrad.ai, simply redirect to komrad.dev without ever reaching AWS.

Every version of the docs lives side by side in the bucket. `latest` follows main, and each release adds a copy of its own, named after its tag. A small function on CloudFront sends a bare visit to `latest`, sends other hostnames to komrad.dev, and fills in `index.html` for directory paths, since a private bucket won't do that for you.

## Publishing

Any push to main that touches the docs publishes `latest`, and each release publishes its own version. You can also publish by hand with `mise run docs:deploy latest`, or name a version instead.

The panel recordings the guides play live outside any one version, so every version of the docs shows the newest take. `mise run docs:recordings` records them against a throwaway instance, and `mise run infra:docs:recordings upload` publishes them.

## Infrastructure

The Terraform lives in [`infra/docs`](https://github.com/harrisoncramer/komrad/tree/main/infra/docs) and shares its state bucket with the engine's. It also reuses the GitHub trust the engine's stack sets up, so apply that one first. Then run `mise run infra:docs:init` and `mise run infra:docs:apply`, with a Cloudflare API token in `CLOUDFLARE_API_TOKEN` that can edit DNS and redirect rules on each domain.
